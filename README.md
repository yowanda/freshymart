# FreshyMart — From farm to your door in 24 hours

A farm-to-table marketplace web app where city buyers order fresh produce
directly from local farmers. Designed and built for the HyperBloom October
UI/UX & Web Design Hackathon.

## The experience

- **Browse:** 14 products with farmer name, village, harvest date, price,
  freshness badge, organic tag, and rating. Filter by category, live search,
  sort by freshness / price / rating.
- **Product detail:** farmer story, harvest freshness, nutrition note,
  quantity stepper.
- **Cart:** quantities, subtotal, delivery fee, free-delivery progress bar
  (free at Rp 75,000), freshness guarantee note.
- **Checkout:** 3 steps — Delivery address (validated) → Payment method
  (Transfer / Cash on Delivery / QRIS) → Confirm — then a success screen with
  order number and a 4-stage delivery timeline.
- **Farmer stories:** meet the growers behind the produce.
- **How it works:** Order → Harvested → Delivered.

## Design system

Warm organic palette (cream `#FFF8EE`, deep leaf green `#1E5631`, tomato
accent `#E4572E`), editorial serif display type + clean sans body, rounded
cards, soft shadows. Mobile-first, accessible: skip link, real labels,
focus-visible outlines, aria-live cart updates.

## Run it

Open `index.html` in any browser. Zero install, no build step, no backend,
no external assets — all visuals are inline SVG + CSS.
